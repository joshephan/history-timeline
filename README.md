# Historical Timeline

An interactive horizontal-scroll timeline visualizing 5,000 years of human civilization — from ancient Mesopotamia to the modern era.

![Historical Timeline](https://img.shields.io/badge/figures-2%2C260-blue) ![Events](https://img.shields.io/badge/events-62-orange) ![Works](https://img.shields.io/badge/works-54-green)

## Features

- **Horizontal scroll timeline** — fixed viewport height, scroll through history
- **2,260 historical figures** with lifespan bars color-coded by category
- **62 major events** displayed as vertical markers
- **54 significant works** (books, treatises, scriptures) positioned along the timeline
- **5 eras**: Ancient, Classical, Medieval, Renaissance, Modern
- **6 categories**: Religious, Political, Philosophical, Scientific, Artistic, Cultural
- **Click-to-expand detail panel** with descriptions and historical significance
- **Category filters** to focus on specific domains
- **Papyrus-textured background** with sepia tones

## Data Source

Historical figures data is sourced from **[Historical Parallax](https://historical.parallax.kr)** ([GitHub](https://github.com/parallax-ai-llc/historical-parallax)) — an open-source archive of 2,526 historical documents maintained by [Parallax AI, LLC](https://parallax.kr).

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- TypeScript
- CSS Modules
- No external dependencies

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
